# Redes

Repositório dos trabalhos da disciplina **DCC042 - Redes de Computadores**.

## Organização do repositório

Os trabalhos estão organizados em pastas individuais, cada uma contendo a atividade ou trabalho correspondente.

Cada trabalho possui um arquivo `README.md` próprio, contendo informações específicas sobre o projeto, incluindo:

* Título do trabalho;
* Requisitos necessários para sua execução;
* Instruções para compilação;
* Instruções para execução;
* Comandos ou funcionalidades disponíveis, quando aplicável.
